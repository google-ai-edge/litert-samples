# TIPSv2-B/14 DPT — depth, surface normals, semantic segmentation

Model recipes, conversion scripts, instructions, and utilities for the TIPSv2-B/14 dense-prediction heads ([google/tipsv2-b14-dpt](https://huggingface.co/google/tipsv2-b14-dpt): metric depth + surface normals + ADE20K segmentation on the frozen [TIPSv2](https://huggingface.co/google/tipsv2-b14) backbone).
