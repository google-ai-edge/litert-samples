# LFM3 1.7B

Model recipes, conversion scripts, instructions, and utilities for LFM3-1.7B, Liquid AI's text model for local agents ([LiquidAI/LFM3-1.7B](https://huggingface.co/LiquidAI/LFM3-1.7B)).

- [`converted/`](converted/): the CPU and GPU files of litert-community/LFM3-1.7B-LiteRT.
- [`google_tensor_g6/`](google_tensor_g6/): a bundle for the Google Tensor G6 NPU (Pixel 11), compiled with your own Tensor SDK access.
