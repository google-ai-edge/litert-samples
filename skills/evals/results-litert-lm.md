"Skill read" lists the skill files the agent opened (a `view_file` step in the Antigravity CLI stream; not observable in Android Studio). A result is ✓ or ✗ followed by the first thing that decided it. The 2026-10-16 rows (Claude Code and Codex CLI, [conditions in the README](README.md#across-agents-2026-10-16)) had only the prompt's skill installed; their skill read is a Skill tool call or a shell command that printed the file, and a parenthesis counts the agent's web searches and the pages it read. The rows marked "(updated 2026-10-16)" are the runs of [After the change of 2026-10-16](README.md#after-the-change-of-2026-10-16): the same conditions, with the skills as updated on 2026-10-16 (this change).
